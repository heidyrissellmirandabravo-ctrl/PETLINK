Porque cada mascota merece volver a casa.

PETLINK conecta a las mascotas con sus familias mediante un collar con código QR y una plataforma web. Si alguien encuentra una mascota, puede escanear su código y consultar su información para ayudarla a regresar con su propietario.

Una pequeña conexión puede hacer una gran diferencia.

¿Cómo ayuda PETLINK?

📱

Escaneo sencillo

El código QR se puede leer con la cámara de un celular, sin instalar una aplicación especial.

🐕

Información útil

Permite consultar la fotografía, las características y el estado registrado de la mascota.

💚

Contacto directo

Facilita la comunicación con el propietario mediante WhatsApp para coordinar el reencuentro.

🔎 Buscar una mascota

Escribe el nombre de la mascota para consultar si está registrada en PETLINK.

🐾 Registrar una mascota

Completa los datos para crear el perfil PETLINK y generar el código QR individual de tu mascota.

Escribe el código de país y el número, solo con dígitos. Este número se utilizará para contactar al propietario.

Selecciona una imagen de hasta 5 MB.

Necesitarás esta clave para administrar los datos de tu mascota. No la compartas con otras personas.

Importante: utiliza únicamente información necesaria para identificar a tu mascota. No escribas tu dirección particular en los campos públicos del perfil.
